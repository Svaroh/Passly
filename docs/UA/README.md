# Документація Passly

Passly — це відкритий, орієнтований на команди менеджер паролів, побудований на принципах offline-first. На відміну від звичайних веб-застосунків, що покладаються на тимчасове кешування, Passly підтримує автономну, повнофункціональну локальну репліку на кожному клієнтському пристрої. Користувачі зберігають безперервний доступ до своїх облікових даних, TOTP-кодів та passkey-ключів у будь-який час — навіть під час тривалих збоїв сервера або повної відсутності мережевого з'єднання.

Цей каталог містить центральні архітектурні специфікації, безпекові моделі, плани розгортання та облік завдань для екосистеми Passly.

## Структура

```
docs/
├── architecture/    # Основні технічні специфікації, моделі безпеки та протоколи синхронізації
├── deployment/      # Плани розгортання інфраструктури (OCI Free Tier, NixOS, Edge Proxy)
├── DONE/            # Зафіксовані звіти про завершені етапи та верифіковані можливості
├── TODO/            # Беклог завдань, заплановані покращення та незавершені ініціативи
├── UA/              # Українська локалізація документації
├── README.md        # Огляд структури документації англійською мовою
└── AGENTS.md        # Інструкції та контекст для AI-агентів розробки
```

Оригінальну документацію англійською мовою див. у [docs/README.md](../README.md).
